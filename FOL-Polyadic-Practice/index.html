Relations in a model

Explore arrows and ordered pairs, then find the models where a sentence is true.

What does an arrow mean?

A model describes a possible situation. A relation tells us which objects stand in a relationship to which other objects.

For example, consider this model:

Domain: 1, 2, 3
a names: 1
b names: 2
R: ⟨1, 2⟩, ⟨2, 1⟩, ⟨2, 2⟩

That means R relates 1 to 2, 2 to 1, and 2 to itself. We can picture the situation like this:

An arrow from 1 to 2 represents ⟨1, 2⟩. The arrow from 2 to 1 represents a different pair. The loop at 2 represents ⟨2, 2⟩. Only the numbered objects belong to the domain.

Rab says that the object named by a bears R to the object named by b. Here a names 1, b names 2, and ⟨1, 2⟩ is in R, so Rab is true. Rba is also true here because ⟨2, 1⟩ is in R. A model can contain one pair without containing the other.

For a familiar example, suppose R stands for “respects,” a names Alice, and b names Bob. Then Rab says that Alice respects Bob, while Rba says that Bob respects Alice. These are different claims: one can be true without the other.

Something stands in a relation

An existential sentence says that at least one object makes a condition true. Here the domain is 1 and 2, a names 1, and R contains only ⟨1, 2⟩.

∃x Rax says that a bears R to something. It is true: the arrow from 1 to 2 shows that 2 is a witness.

∃x Rxa says that something bears R to a. It is false: no arrow ends at 1. Look carefully at which position contains x.

A loop can count: if ⟨1, 1⟩ were in R, 1 could be a witness for either sentence. A witness need not be a different object from the one named by a.

Everyone stands in a relation

A universal sentence says that every object in the domain makes a condition true. To check it, look at each object. One object that fails is enough to make the sentence false.

Here the domain is 1 and 2, a names 1, and R contains only ⟨1, 1⟩.

∀x Rax says that a bears R to every object. It is false: a bears R to 1, but not to 2. Object 2 is a counterexample.

“Every object” includes a itself: for this sentence to be true, there must also be a loop at the object named by a.

Something relates to something

We already know how to say that a particular object bears R to something: ∃y Ray says that the object named by a bears R to at least one object.

What if we want to say that something bears R to something, without specifying that the first object is a? We can use another existential quantifier: ∃x ∃y Rxy. Look for at least one arrow. A loop counts: x and y can be the same object.

A witness for ∃x ∃y Rxy is still just one object: an object you can choose for x so that ∃y Rxy is true. In other words, it must have an arrow to at least one object. In the witness activity, choose the starting object, not the object at the other end of the arrow.

We can also put a more complicated condition after the quantifiers. ∃x ∃y (Rxy ∧ Rya) says that something bears R to an object that bears R to a. The same y must work in both parts. ∃x ∃y (Rxy ∧ Ryy) says that something bears R to an object that bears R to itself.

Everything relates to everything

∀x ∀y Rxy says that every object bears R to every object. For each choice of x, check every choice of y. This includes the case where x and y are the same. To show that the sentence is false, a counterexample is an object x for which ∀y Rxy is false—for example, an object that does not bear R to itself.

Something relates to everything

∀y Ray says that the object named by a bears R to every object. But we might instead want to say that something bears R to everything, without saying which object it is.

We can use an existential quantifier with the universal statement: ∃x ∀y Rxy. Look for one object x that has an arrow to every object in the domain. The same x must work for all of those arrows; it does not have to be the object named by a.

A witness is one object you can choose for x such that ∀y Rxy is true for that object: it must bear R to every object.

Everything relates to something

∀x ∃y Rxy says that everything bears R to something. Check each object x and make sure it has at least one outgoing arrow. The object y may differ for different choices of x, though it can also be the same.

Compare the two orders

In this model, the domain is 1 and 2, and R contains ⟨1, 2⟩ and ⟨2, 1⟩.

∀x ∃y Rxy is true: 1 has an arrow to 2, and 2 has an arrow to 1. But ∃x ∀y Rxy is false: neither object has an arrow to every object, since both loops are missing.

Two ways the conditional can be true

Suppose the domain is 1 and 2, a names 1, and R contains ⟨1, 2⟩ and ⟨2, 1⟩. Here a bears R to 2, and 2 bears R back to a. For 1, the antecedent is false because ⟨1, 1⟩ is absent. So ∀x (Rax → Rxa) is true.

Now suppose R is empty instead. The sentence is still true: a does not bear R to any object, so for each object the “if” part is false. The conditional is true for each object, even though there are no arrows.

Truth in a model

Explore a sentence, then find the models that make it true. Practice as much as you like.

What is a model?

Models describe logically possible situations. We can ask whether a sentence is true in the situation described by a model.

For example, suppose a model has three objects, 1, 2, and 3. The name a names object 1, and P represents a property that applies to exactly objects 1 and 3. A second property, Q, applies to exactly objects 2 and 3. We can picture the situation like this:

How to read this picture

The blue region labeled P contains exactly the objects with P; the yellow region labeled Q contains exactly the objects with Q. An object in both regions has both properties. Only the numbered objects belong to the domain; empty space adds no objects. Italic letters beneath an object are its names.

We can now ask whether sentences are true in this situation. For example, Pa says that the object named by a has property P. Since a names 1 and P applies to 1, Pa is true in this model.

In contrast, Qa says that the object named by a has property Q. Since a names 1 and Q applies only to 2 and 3, Qa is false in this model.

For a familiar example, if a names Alice and P represents the property of being pretentious, Pa says that Alice is pretentious.

About these model pictures
In three-object pictures, 1, 2, and 3 stay in the same positions. P has a solid blue outline; Q has a dashed yellow outline. Both outlines appear when the properties apply to the same objects. “P: none” or “Q: none” means that no objects have that property.
Practice pictures show the predicates and names used in the sentence. Pictures with one, two, or four objects use P and Q labels beside the objects instead of regions. You can hide the practice pictures and use the written model descriptions.

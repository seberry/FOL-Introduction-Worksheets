01 / Wrong main connective

How do I find the main connective?

The main connective is the connective that operates on the sentence as a whole. Parentheses help you see what each connective applies to.

The main connective is the last connective you would add if you were building the sentence in Formula Factory.

Play Formula FactoryBuild formulas and pay attention to which connective you add last.↗

¬(P & Q)

1. Combine P and Q: P & Q

2. Negate the result: ¬(P & Q)

Main connective: ¬. The & was added earlier.

¬P & Q

1. Negate P: ¬P

2. Join it to Q: ¬P & Q

Main connective: &. It joins the two sides.

02 / Missing or repeated rows

Truth tables for 3 and 1 atomic sentences

If a formula contains three different atomic sentences—for example P, Q, and R—your truth table needs 8 rows. Each atom can be true or false, so there are 2 × 2 × 2 = 8 possible assignments.

How do I set up the rows for three atoms?

On your paper, just write P, Q, R, draw a horizontal line under them, and fill in the T’s and F’s. The colored version beside it shows the 4–2–1 pattern that helps you include every combination exactly once.

P: four T’s, then four F’s.

Q: two T’s, two F’s, then repeat.

R: alternate T and F on every row.

04 / Conclusion or table setup unclear

Truth tables for checking validity

If you weren’t sure which sentence was the conclusion, start there. Then write the premises and conclusion side by side so you can compare their truth values on each row.

P → Q, Q ∴ P

What is the conclusion of this argument? What are the premises?

The symbol ∴ means therefore. The sentence after it is the conclusion: P. There are two premises before it: P → Q and Q.

Once you’ve filled in your short-form truth table, check for a row where all premises are true and the conclusion is false. If you find one, the argument is invalid (not valid). If there is no such row, it is valid.

The circled T, T, F in the third row shows this argument is invalid (not valid). Read only the whole-sentence values: both premises are T and the conclusion is F. With three premises, the pattern would be T, T, T, F.
